
# 📊 Amazon Prime Video Data Analytics Dashboard

## 📌 Project Overview

This project is an end-to-end data analytics dashboard built using **Power BI** to explore and visualize the Amazon Prime Video content dataset. The dashboard provides interactive insights into content trends, genre distribution, release patterns, ratings, and country-wise content availability.

The goal of this project was to transform raw data into meaningful business insights through effective data cleaning, modeling, and visualization.

---

## 🚀 Dashboard Highlights

* 📅 **Release Trends (1920–2021)** – Analyze how content production has evolved over the years.
* 🎬 **Total Content** – **9,655** movies and TV shows.
* 🎭 **Genres Covered** – **519** unique genres, with **Drama** being the most common.
* 🎥 **Directors** – **5,771** directors represented in the dataset.
* 📈 **Highest Content Release Year**

  * **Movies:** 2021 – **1,139** releases
  * **TV Shows:** 2021 – **303** releases
* 📊 **Genre Distribution** – Visual breakdown of content across different genres.
* ⭐ **Content Ratings** – Comparison of ratings for Movies and TV Shows.
* 🌍 **Country-wise Content Distribution** – Explore content availability across different countries.

## 📈 Key Insights

* Content production has grown significantly over the last two decades.
* Drama is the most frequently released genre on Amazon Prime Video.
* 2021 recorded the highest number of both movie and TV show releases.
* The dashboard enables users to explore trends by genre, country, ratings, release year, and content type.

The objective of this project was to gain practical experience in the complete data analytics workflow—from cleaning raw data and transforming it into a structured model to creating an interactive dashboard that communicates actionable insights effectively.
